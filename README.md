# ESPHome-Assist-No-wakewords

This is a fork of the official ESPhome Voice Satelite firmware. It is run by a recurring action to strip the wake words that come with the firmware: Okay Nabu, Hey Jarvis. This is only useful if you want to add custom wake words. The overall storage on the device is rather small and removing the stock wake words that you dont want for full custom ones makes them run without degrading the voice recognition. 

If you want to generate your own wake words, you can find my wake word training notebook here: https://github.com/Rogusliv/MWW-gen
If you want to use wake words that have been generated by others, check out that repo here: https://github.com/TaterTotterson/Tater-Wake-Words
If you want to see some wake words made by my notebook check out this repo: https://github.com/Rogusliv/RogusMWW
